# Glossary

| Term | Meaning |
|---|---|
| Software house | A Pakistani software / IT services company |
| Careers source | Where a company publishes openings: careers page, hiring platform feed, or hiring email |
| Hiring platform | Third-party ATS with a public job feed (e.g. Greenhouse) |
| Snapshot | Cleaned text + fingerprint of a careers page at one fetch |
| Opening | One internship or job extracted from a careers source |
| Fit score | 0–100 match between an opening and the profile, with reasons |
| Eligibility warning | A requirement the user may not meet; never hides the opening |
| Demo mode | Public, read-only view using fictional sample data |
| PSEB | Pakistan Software Export Board (runs the Tech Hub directory) |
